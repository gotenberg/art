Pixel versions of the logos and a Gutenberg hand press live in [`pixel/`](pixel), as SVG and
640 px PNG. The animated press is an SVG that cycles through its frames, with a PNG sprite
sheet beside it. The maps and the press drawing are in `pixel/build.py`; edit them and run
`python3 pixel/build.py` to regenerate the files.
