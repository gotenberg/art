## Pixel art

Pixel versions of the logos, a Gutenberg hand press and litho's stamped sheet live in
[`pixel/`](pixel), as SVG and 640 px PNG, with an animated SVG and a PNG sprite sheet for
the press and the litho logo. The maps and the drawings are in `pixel/build.py`; edit them and
run `python3 pixel/build.py` to regenerate the files.
