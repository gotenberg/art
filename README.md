Pixel versions of the logos, a Gutenberg hand press and litho's stamped sheet live in
[`pixel/`](pixel), as SVG and 640 px PNG. The animated pieces are SVGs that cycle through their
frames, with a PNG sprite sheet beside each. The maps and the drawings are in `pixel/build.py`;
edit them and run `python3 pixel/build.py` to regenerate the files.
